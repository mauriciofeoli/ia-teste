# QA Playground

Um projeto pequeno para praticar qualidade de software com mudancas reais e faceis de revisar.

## Ideias de contribuicao

- Adicionar um novo caso de teste
- Melhorar uma mensagem ou estado vazio
- Criar um issue com passos para reproduzir um problema
- Escrever testes automatizados para os componentes

## Como executar

```bash
npm install
npm run dev
```

Contribuicoes devem explicar qual comportamento foi protegido e como validar a mudanca.
